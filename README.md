# MotoRodeo

Веб-приложение для организации соревнований **МотоРодео**: учёт участников, проведение мероприятий, заявки, судьи и жизненный цикл событий.

## Возможности

- Регистрация и вход пользователей (cookie-аутентификация)
- Подтверждение email и восстановление пароля через SMTP
- Профиль участника (имя, позывной, транспорт)
- Создание и редактирование мероприятий: место, дата, регистрация, судьи, группы
- Подача заявок на участие и модерация (подтверждение / отклонение)
- Жизненный цикл события: планируемое → сетка готова → завершено / отмена
- Администрирование аккаунтов: список, блокировка / разблокировка
- Экспорт подтверждённых участников (печать / CSV)
- Внешнее API для подтверждения и отклонения заявок (API-ключ)

## Структура решения

```
MotoRodeo/
├── MotoRodeo.Web/     # MVC-приложение, контроллеры, представления, API
├── MotoRodeo.BL/      # Бизнес-логика, команды, хендлеры, email
├── MotoRodeo.DAL/     # Сущности, контекст EF, миграции, seed
└── MotoRodeo.slnx
```

## Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- PostgreSQL 14+ (или совместимый сервер)
